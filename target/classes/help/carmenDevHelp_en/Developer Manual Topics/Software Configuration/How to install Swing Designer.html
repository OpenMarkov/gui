How to install Swing Designer

To use Swing Designer as a plugin in your Eclipse application, please do the following steps:

1. Download the Swing Designer v6.9.0 (as it includes the GroupLayout Java 1.6 layout support)

2. Install the plugin in your system doing a double click in the downloaded file

3. You will be asked for the installation directory and the Eclipse version to install in. Please select one or more versions.

4. Then, three plugins will be shown before be installed.

    - Designer_v6.9.1

    - Shared v.5.5.0

    - DShared v7.0.0

5. Then, you will start Eclipse and activate the plugin (free trial version or definite version)
