Exportar las preferencias de usuario

 Exportar las preferencias de usuario a un archivo, permite que el usuario pueda llevar a otro equipo esta configuración o enviarla a otro usuario. Para realizarlo, simplemente debe pulsar el boton "Exportar preferencias" en la parte inferior de la ventana.

Para exportar la configuración de usuario, debe:

  1. Pulsar en el menú principal, opción "Herramientas"
  2. Pulsar en "Configuración CARMEN"
  3. La ventana de preferencias de Carmen se mostrará
  4. Pulsar en el botón "Exportar preferencias" de la parte inferior de la ventana
  5. La ventana de dialogo "SALVAR" aparecerá para poder dar nombre al fichero donde se realiza la exportación de la configuración
  6. Dar el nombre al fichero y salvarlo (formato xml)
  7. La ventana de dialogo se cierra. Ya está.
