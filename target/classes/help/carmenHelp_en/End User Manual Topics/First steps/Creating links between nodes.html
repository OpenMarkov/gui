Creating a link between two nodes

Try it now by following the steps below. After you have created your new nodes you will decide how to link between them using the directed link and you will see its graphical representation in the network area.

  1. Choose "Insert new links" from the Edit Menu or press "Insert new Links" icon on the upper side toolbar.
  2. The mouse will be now converted in an arrow cursor to allow you to draw the line between the two selected nodes (source and target).
  3. Click on the source node and DO NOT RELEASE the button.
  4. Move to the target node and see how the line is following your mouse, and click on the target node
