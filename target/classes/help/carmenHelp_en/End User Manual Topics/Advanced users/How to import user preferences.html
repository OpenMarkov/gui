Importing user preferences

 

To import the preferences to allow a user to open CARMEN in a different equipment or to set the preferences with another user preferences, just click on the button "Import preferences" in the bottom area of the CARMEN window

 To import a user configuration, you must:

  1. Click on main menu, option "Tools"
  2. Click on "CARMEN preferences"
  3. The Carmen user preference window will be shown
  4. Click on the "Import Preference" button in the bottom side of the window
  5. A "OPEN" dialog window will appear to set the name of the file to import the preferences
  6. Select the file that contains a Valid CARMEN User Preferences and open the file (xml format)
  7. The dialog window will be closed. It is done.
