Internationalization Guide

What is and why is required the Internationalization?

 

There are a lot of inhabitants in the world. We hope that lots of them will be interested in this software and we do not want to put barriers for use it.

The Java programming language was the first language designed from the ground up to support internationalization. It used, internally, Unicode for all strings. The Unicode support makes it easy to write Java programmes that manipulate strings in any of the multiple languages.

But, having Unicode support is not enough to do internationalization. Programs must be aware about the language changes.

Although CARMEN is just supporting English and Spanish languages at this moment, it is ready for any other language on just one click.

In Java popular terms, internationalization is named "i18N", so we use this notation from now and on.

 

i18N Implementation details

 

To do i18N, a package "carmen.gui.localize" has been incorporated to CARMEN.

Main classes on this package are StringResource, StringResourceLoader, Languages and the Listener Interface. Listene Event and Listener Handler classes.

All classes/elements that want to be informed about changes on the languages must implement the StringResourceLocaleChangeListener interface and the method "processStringResourceLocaleChange" as below:

 

StringResourceLoader.getUniqueInstance().addStringResourceLocaleChangeListener(
    new StringResourceLocaleChangeListener() {

        public void processStringResourceLocaleChange(final LocaleChangeEvent event) {

        }

    }

);

This call can be inserted on the main class or inside the individual visual components of a Swing container (JDialogs, JPanel, JButton, JComboBox, etc...)

 

Step by Step programming guide

 

1. Create your own visual class with the different elements

2. In the default constructor of the visual class you must add the following sentences:

2.1 Sentence in the default constructor to be added

dialogStringResource = StringResourceLoader.getUniqueInstance().getBundleDialogs();

yourContainer.setText(dialogStringResource.getString("yourContainer.Title.Text");

2.2 Listener for the title and top-level texts 

    StringResourceLoader.getUniqueInstance().addStringResourceLocaleChangeListener(

            public void processStringResourceLocaleChange(final LocaleChangeEvent event) {
