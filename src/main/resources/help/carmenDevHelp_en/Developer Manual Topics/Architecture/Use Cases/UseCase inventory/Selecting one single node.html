Selecting one single node

Use case: Selecting one single node

Comment: This use case is initiated by the user when he/she wants to select a node, deselecting all the rest elements. The description can be seen in the table.

Actor: User

Normal course

Alternative courses

1.When the type of editing is the selection of objects, the user presses with the left mouse button, with the SHIFT key pressed, on a non selected node of the network.


2.The program deselect all the elements selected by executing the use case Deselecting all the visual elements.


3.The node that has been pressed is selected.


4.The use case Updating the menus when changing the selected element is executed.
