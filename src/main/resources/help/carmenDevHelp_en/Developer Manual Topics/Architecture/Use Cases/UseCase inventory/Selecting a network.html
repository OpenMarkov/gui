Selecting a network

Use case: Selecting a network

Comment: This use case is enabled when selecting a different window than the one that is currently selected in the multi-document environment.

Actor: User

Normal course

Alternative courses

1.The user selects a different window than the one that is currently selected in the multi-document environment


2.In the window list menu of the menu dependant on the multi-document environment is marked the item corresponding to the selected window and the others are unchecked.


3.If the network associated with the window is not saved and it has been modified, the application enables the option to save a network from the main menu and the toolbars.

3.1.If the network associated with the window is already saved, the application disables the option to save a network from the main menu and toolbars.

4.The main menu and toolbars options related to the scale factor with which the network is displayed are updated.


5.The main menu and toolbars options to show the state of the clipboard are updated.


6.The main menu and toolbars options related to the redo and undo actions are updated.


7.The main menu and toolbars options related to the elements (nodes and links) that can be adde to the network selected* are updated.

* In a Bayesian network can be added only probabilistic nodes and links. In an influence diagram can be added any type of node and links.


8.The main menu and toolbars options related to the way that the nodes are showed (by name or by title) are updated.


9.The main menu and toolbars options that depends on the number and type of elements (nodes and links) selected* are updated.

*Some options as edit the properties of a node will only be available when a single node and no link is selected. The same happens with copy and cut options that will only be enable when only nodes and any links are selected.
