Creating a link

Use case: Creating a link

Comment: After creating some nodes, the user can create a new link as described in the table.

Actor: User

Normal course

Alternative courses

1.When the type of editing is the creation of links, the user presses on a node of the network with the left mouse button without pressing any key.


2.A new link appears whose initial point is at the center of the selected node and whose final point, in the shape of an arrowhead, is in the position of the cursor.


3.If the user moves the mouse, the final extreme of the link will change to the new position of the mouse cursor and the use case will back to this same point.

3.1.If the user does not move the mouse, the use case will remain in point 3.

3.2.If the user releases the mouse button, the use case will skip to point 4.

4.If the user releases the button when the mouse cursor was on a node, it will go to point 5.

4.1.If the user releases the button when the cursor was on the same node on which he/she had pressed or on the empty back of the net panel, the use case ends.

5.If the link was not created, there was not any other link in the opposite direction, no cycles are created and the new link is allowed, it is created by painting a new link between two nodes in the sense that the user has chosen.

5.1.If the link was already created, there was another link in the opposite direction, cycles are created and the new link is not allowed, it is not created and the use case ends.

6.The potential tables are modified in the destination node with the values assigned to the new parent and their corresponding states.

6.1.If in creating tables an error is detected, the new link is not created and the use case ends.

7.A new point to undo and redo the link creation is created.


8.The use case Updating menus when modifying a network is executed.


9.The network is marked as modified (if it was not already), placing an asterisk at the title of the window in which is being editing.
