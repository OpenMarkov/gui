Loading a network

Use case: Loading a network

Comment: It will be carried out when the user wants to load a network stored in a file.

Actor: User

Normal course

Alternative courses

1.The user indicates to the program that he/she wants to open and existing network.


2.The program asks the user to type or choose the file that contents the network information.


3.The user chooses a file or writes its name.

3.1.If the user does not want to open the network, he/she can cancel the operation, ending the use case.

4.The program reads the file information and checks that it is correct.

4.1.If the file information is not correct, the program informs the user and ends the operation.

5.The program creates a new window associated to the network in the multi-document environment which title will be the name of the network.


6.All options of the menu related to multi-document environment are enabled (if they were not already).


7.A new item is created in the dependent menu of the multi-document environment that will be associated to the new window.


8.The new window is selected and the use case Selecting a network is enabled.
