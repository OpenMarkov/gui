Saving a network

Use case: Saving a network

Comment: Use case executed when the user wants to save the information of a network in the same file than the one which has been loaded from.

Actor: User

Normal course

Alternative courses

1.The user indicates to the program that he/she wants to save the information of the network.


2. If the network has a file associated, the program saves the information of the network in this file.

2.1.If the network does not have a file associated, the program will execute the use case Saving a network as.

3.The title of the window that contains the network is modified to eliminate the asterisk that precedes the title, if the network had not been saved.


4.The option to save a network of the main menu and toolbars is disabled.
