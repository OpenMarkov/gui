Updating the menus when changing the selected element

Use case: Updating the menus when changing the selected element

Comment: This use case is executed by the abstract actor menu updater. Use case and abstract actor have been created because the cut, copy, and delete options and the properties of the node are allways enabled or disabled depending on the number and the type of elements that are selected at that moment. Therefore, all use cases related to the change of the selection of elements, include this one. The description of the use case is shown in the table. Specified options are enabled or disabled in the pop-up menus of the network, in the main menu and in the editing toolbar.

Actor: User

Normal course

Alternative courses

1.Menu updater starts the updating process.


2.If there is some element selected in the network, option delete is enabled.

2.1.If there is not any element selected, option delete is disabled.

3.If there are nodes but no links selected, options copy and cut are enabled.

3.1.If in addition to the nodes there is some link selected or if there are not nodes selected, options copy and cut are disabled (*).

*Must be taken into account, as discussed below, that when a node is copied to the clipboard, will also be copied all links, regardless of that the nodes which it is linked to are copied. When pasting the node, its links will be created whenever the node of the other side is pasted or it is already created in the network. When pasting the node, at least one end of each link will exist. For this reason, copy a single link is not allowed, since when pasting may not exist any of its ends.

4.If there is just one node but no links selected, properties of the node option is enabled.

4.1.If there is not any node selected, if there are more than one node selected or if there is some link selected, properties of the node option is disabled.

5.If there is just one link and no nodes selected, properties of the link option is enabled.

5.1.If there is not any link selected, if there are more than one selected or if there is some node selected, properties of the link option is disabled.
