Updating menus when modifying a network

Use case: Updating menus when modifying a network/b>

Comment: This use case is executed by the abstract actor menu updater. It has been created because the undo and redo options are turned on or off depending on whether if it is possible or not undo or redo. The option to save the network is enabled whenever it is modified. Therefore, all use cases related to the modification of a network, include this one. The description of the use case is shown in the table. Specified options are enabled or disabled in the main menu and in the editing toolbar.

Actor: User

Normal couse

Alternative courses

1.Menu updater starts the updating process.


2.Undo option will be enable whenever there is some modification in the network that has not been undone yet.

2.1.Undo option will be disabled whenever no modifications of the network have been done.

2.2.Undo option will be disabled whenever all modifications of the network have been undone.

3.Redo option will be enable whenever there is some modification undone that has not been redone yet.

3.1.Redo option will be disabled whenever no modifications of the network have been done.

3.2.Redo option will be ddisabled whenever it has not been undone some modification or all modifications undone have been already redone.

4.Option to save the network is enabled.
