Copying nodes to the clipboard

 

Use case: Copying nodes to the clipboard

Comment: This Use case allows the user to copy certain nodes to the clipboard of the program to paste them later. The copy option will be only available if there is any selected node and no link. Will be copied to the clipboard information of these nodes and the one of the links that go out and come in to them.

Actor: User

Normal course

Alternative courses

1.When the edition type is the selection of objects and there are only selected nodes, the user presses the key combination CONTROL + C or selects the option to copy which is available both in the main menu as in the standard toolbar or presses on option of the popup menu of the node.


2.The program copies in the clipboard the information of all selected nodes and all links that go out and come in to them, including the links that bind them to other nodes that are not copied. This information replaces the one that was stored in the clipboard.


3.The option to paste that is in the main menu, on the standard toolbar and at the drop-down menu of the nodes is enabled.
