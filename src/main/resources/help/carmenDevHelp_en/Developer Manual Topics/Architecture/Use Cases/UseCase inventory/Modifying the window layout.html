Modifying the window layout

Use case: Modifying the window layout

Comment: This use case does not really exist. It is a generic name for a set of similar use cases that are used to change the arrangement of windows within the multi-document environment. Use cases that include are: organizing in cascade, organizing in mosaic, minimizing all and restoring all. The first organizes the windows in cascade restoring those that are minimized. The second fills the entire space of the main window with the internal windows, so that none overlap with others. The third minimizes all windows that are not and the fourth restores all minimized. In all cases, the window currently selected will continue selected after the operation.
The description of any of these cases can be seen in the table.
