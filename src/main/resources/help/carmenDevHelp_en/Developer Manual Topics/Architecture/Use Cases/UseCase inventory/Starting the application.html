Starting the application

Use case: Starting the application

Comment: This use case will be executed when the user starts the application.

Actor: User

Normal course

Alternative courses

1.The user starts the program without parameters.

1.1.If the user enters the program startup parameters they are ignored and it goes to point 2.

2.The program reads the program configuration file.


3.The following attributes are read from the configuration file: the necessary attributes to set the positions of the main window and message window, the colors of the types of nodes, the directories where the networks are located, the languages and the resources needed for the program.

3.1.In case of error (if the configuration file cannot be read), the elements take a default value.

4.The language for the texts of the program are established using the language saved as initial data in the file of configuration.

4.1.If the configuration file is not found, default configuration options are established. The program default visualization language is the one that user has established in his/her system/computer.

5.If there are texts for the selected language, that language will be established as the final language for the texts of the program.

5.1.If the established laguage cannot be used because there are not texts for it, English (default language) will be used as the final lenguage for the texts of the program.

6.Main window, main menu, toolbars and multi-document environment are created.


7.All options of the main menu and the toolbars are disabled with the exception of the following options: creating a new network, openning an existing network and showing the message window. 


8.The clipboard of the program is created.


9.Message window is created and the standard flow System.out and System.err are replaced to allow that their data will be shown in this window.
