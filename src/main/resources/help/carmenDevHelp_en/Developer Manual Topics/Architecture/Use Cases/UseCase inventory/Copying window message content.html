Copying window message content

 

 

Use case: Copying window message content

Comment: This use case is initiated by the user when he/she wants to copy the contents of the message window on the system clipboard.

Actor: User

Normal course

Alternative courses

1.The user indicates to the message window that he/she wants to copy the contents of the message window to the clipboard of the operating system.

1.1.If the message window is not visible, the user must execute the Use case Setting message window at the front.

2.The program copies the contents of the message window to the clipboard of the operating system.
