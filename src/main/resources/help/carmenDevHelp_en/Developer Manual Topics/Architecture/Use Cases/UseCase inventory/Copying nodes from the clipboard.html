Copying nodes from the clipboard

 

Use case: Copying nodes from the clipboard

Comment: This use case allows to paste the information from the clipboard to the current network.

Actor: User

Normal course

Alternative courses

1.When the edition type is the selection of objects and if the clipboard contains information, the user presses the key combination CONTROL + V or selects the option to paste that is available in the main menu as in the standard toolbar or presses on the option of the emerging menu on the back of the panel network.


2.All items are deselected.


3.Use case Updating the menus when changing the selected element is executed.


4.The program takes a node from the clipboard and if it is suitable for the network *, it is created in its original location.

 *A given node is suitable for a network if it can be created on it. For example, decision and utility nodes are not suitable for Bayesian networks but for influence diagrams.

4.1.If the node exists, it tries to create it by adding "_X" to the name until it can be created. X is an integer from one that is increased until there is not a node with that name. The new node is created a little removed from its original location.

5.While there are nodes in the clipboard, it returns to point 4.

5.1.If there are no more nodes to create, it goes to point 6.

6.The program takes a link from the clipboard and creates it by joining the two nodes as if they are stuck as they were already in the network.

6.1. If one of the nodes that join the link was not copied to the clipboard and no longer exists, the link is not created.

7. While there are links into the clipboard, it returns to point 6.

7.1.If there are no more links to create, it goes to point 8.

8.All the nodes created are selected


9.The use case Updating the menus when changing the selected element is executed.


10.A new point to undo and redo the pasting of the nodes is created.


11. The use case Updating menus when modifying a network is executed.

 

12.The network is marked as modified (if it was not already), placing an asterisk at the title of the window in which is being editing.
