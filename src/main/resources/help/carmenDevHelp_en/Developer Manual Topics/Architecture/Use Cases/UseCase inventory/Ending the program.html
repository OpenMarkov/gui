Ending the program

Use Case: Ending the program

Comment: This use case will be initiated by the user when he/she wants to close the program.

Actor: User

Normal course

Alternative courses

1.The user indicates to the program that he/she wants to exit.


2.If there is a window on the multi-document environment, it is closed by running the use case Closing a network

2.1.If there is no open window, it goes to point 4.

3.If the window has been closed, it goes to point 2.

3.1.If the window has not been closed, it can not end the program.

4.User's properties setting are saved (language, positions of the main window, directories, recent files open) and the program is ended.
