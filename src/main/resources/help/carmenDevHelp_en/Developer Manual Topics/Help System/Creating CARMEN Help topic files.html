Creating CARMEN Help topic files

Carmen Help conventions

To have an unique Help view, it is really important that all the contributors to the CARMEN Help System will follow the same convention. This section summarizes all the conventions to be done in the files.

  • Name of the file
  • Id of the file
  • File Structure
  • CSS Template
  • Directory Structure
  • Table of content file
  • Images

Name of the file

The name of the file will have enough meaning to clearly identify in the structure.

Only HTML files are allowed.

ID of the file

When created, the file must be clearly identify with an ID in the map file

File structure

All the files will follow the following internal structure:

  • one head
    • with the reference to the CSS (be careful with the level of directories)
    • with the title as described before
  • one body (with background color WHITE)
    • Title of the document with style H1 and the Carmen Logo with size 32
      • Select c3_32.gif (blue Carmen Logo) for Developer Manual Topics
      • Select c2_32.gif (yellow Carmen Logo) for End User Manual Topics
    • A header line in Blue color and size 2
    • Using H2 for main sections
    • Using H3 for main subsections
    • Using H4 for internal sections
    • Using <pre> for source code descriptions

as in the following example:

<html>
    <head>
        <meta content="text/html; charset=Cp1252" http-equiv="Content-Type">
        <meta name="generator" content="Helen">
        <link type="text/css" rel="stylesheet" href="../../javahelp.css">
        <title>Creating CARMEN Help JAR files</title>
    </head>
    <body bgcolor="#ffffff">
        <h1>
        <img border="0" hspace="0" width="32" height="32" 
        src="../../images/carmenHelpIcons/c3_32.gif">
            &nbsp;Creating CARMEN Help topic&nbsp;files
        </img>
        </h1>
        <hr size="2" align="left" color="blue" width="100%">
        <h2>
            Carmen Help conventions
        </h2>
        <p>
            the content of the Help Topic
        </p>
    </body>
</html>

CSS template

All files will use the same Java Code Style Sheet located in the root Help Project directory (javahelp.css)

Directory structure

All files will be located under a meaningful directory and grouping as much as possible.

Table of Content File (toc.xml)

Be sure to remove any item from the Table of content file (toc.xml) when adding new pages

Images

All images to be used in the Help will be located under one of the three following directories:

  • carmenHelpIcons - if the icon is related to the Carmen help system (not the Carmen project itself)
  • carmenIcons - if the icon is one of the Carmen icons you must copy also here
  • screens - copy here any screen hardcopy you will take to enhance the help topic description
