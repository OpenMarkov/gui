Saving the network

Try it now by following the steps below. After you have created your new network , you will want to store safely in your computer.

  1. Choose "Save Network" (or "Save as ...") from the File Menu or press "Saves the actual network" icon on the upper side toolbar.
  2. The Save Network dialog box will appear.
  3. Choose the directory to save the network and type a name for the new network.
  4. As you can see the type of the file is set to "Carmen files (.xml)" by default, but you can also select the Elvira program type "Carmen files (.elv)"
  5. Press Ok to save the network.
