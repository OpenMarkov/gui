Creating an Utility node

Creating an Utility node (in an Influence Diagram)

Try it now by following the steps below. After you have created your new node, you will see its graphical representation in the network area.

  1. Choose "Insert utility nodes" from the Edit Menu or press "Insert new Utility node" icon on the upper side toolbar.
  2. The mouse will be now converted in a special cursor with the arrow and the Utility icon.
  3. After this, chose "Object selection" from the Edit Menu or press "Object selection" icon on the upper side toolbar.
  4. Click now on the new node you have created to display the Node Properties dialog.
  5. Type a name for the new node (if you do not like the default assigned name).
  6. You can set values for the Relevance, Purpose, Type of the variable associated with this node (Discrete, Discretize or Continuous) and write a comment in the Definition tab section.
  7. Then, you can add the parents for this node (if any) in the Parents tab section.
  8. Then, depending on the type of the variable, you can set the discrete values or the partitioned intervals for it.
  9. Press Ok to create the new node.
