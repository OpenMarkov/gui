Setting node properties

The node has different properties you must set. It is important to set the following ones:

  1. Setting definition of the node (Name, Relevance and Purpose, amongst others)
  2. Type of variable that the node is describing
  3. States of the node (either it is describing a discrete or a discretized variable)
  4. Parents
  5. Probability tables
  6. Canonical model to use
