Frequent Asked Questions

What if a red message appears in the Message Window

If, in the Message window, a red message appears, please, press the "Copy" button you can see in the upper side of the Message window.

This action will copy the content of the Message window to the clipboard so you can send us in a e-mail.

Although CARMEN has been designed following strict Software Engineer principles which make very unusual those red messages, the Message window is the mechanism that has been implemented to capture any unexpected conditions, in order to be later on analysed by developers to improve the quality of the source code, and avoiding your work to be disrupted.

What if some functions do not work properly

Please check that your system is compliance with the pre-requisites to run CARMEN.

These pre-requisites are:

  • Java version 5 or higher. You can find from Official Java web site here
  • At least, 256 Mb of RAM memory in your computer
  • Network files from one of the following formats: Carmen XML, Elvira or Huggin
