Changing the value of a preference

To change the value of a CARMEN user preference, you must:

  1. Click on main menu, option "Tools"
  2. Click on "CARMEN preferences"
  3. The Carmen user preference window will be shown
  4. Click on the preference you want to configure
  5. The value for the preference will be shown in the right panel of the window
  6. Click on the value and set the new value
  7. Save the new configuration clicking in the "SAVE" button in the bottom side of the window
