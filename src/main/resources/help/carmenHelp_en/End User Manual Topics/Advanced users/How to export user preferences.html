Exporting user preferences

To export the preferences to allow a user to open CARMEN in a different equipment or to be sent to another user, just click on the button "Export preferences" in the bottom area of the CARMEN window

 

To export a user configuration, you must:

  1. Click on main menu, option "Tools"
  2. Click on "CARMEN preferences"
  3. The Carmen user preference window will be shown
  4. Click on the "Export Preference" button in the bottom side of the window
  5. A "SAVE" dialog window will appear to set the name of the file to export the preferences
  6. Set the name and save the file (xml format)
  7. The dialog window will be closed. It is done.
