Recuperar opciones por defecto

CARMEN permite recuperar la configuración inicial de preferencias si, por cualquier motivo, las que el usuario ha definido fallan o dan problemas.

Para hacer esto, debe simplement pulsar el botón "Resetear preferencias de usuario".

CUIDADO: NO PRESIONE EL BOTON A MENOS QUE ESTE SEGURO DE QUERER RESTAURAR LAS PROPIEDADES POR DEFECTO.

NO SE MUESTRA NINGUN MENSAJE DE ADVERTENCIA TRAS PULSAR EL BOTON. SIMPLEMENTE SE RECUPERAN.
