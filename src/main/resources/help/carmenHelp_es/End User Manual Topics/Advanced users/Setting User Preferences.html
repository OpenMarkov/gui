Ajuste de Preferencias de Usuario

Cada usuario puede establecer algunos valores de determinadas propiedades internas de CARMEN. Estas propiedades, conocidas como "Preferencias de Usuario", son accesibles desde un panel de diálogo en el menú principal (Herramientas/Configuración de Carmen) y son almacenadas definitivamente en el propio registro de usuario (sistema operativo independiente).

¿Qué propiedades puede establecer un usuario?

Las propiedades que un usuario puede establecer o modificar son:

  • Colores de los nodos (de probabilidad, decisión y utilidad)
  • Colores de las celdas de las tablas
  • Directorios de ubicación de los idiomas para la aplicación
  • Posición inicial relativa de la ventana de CARMEN
  • Tamaño inicial de la ventana de ayuda
  • Idioma de usuario

 

 

Propiedades por defecto

Por otro lado, si CARMEN es ejecutado por primera vez y, por lo tanto, no hay preferencias de usuario específicas, el programa crea una configuración por defecto que cada usuario, si es necesario, puede recuperar en cualquier momento desde el menú Configuración, usando el botón ("Restaurar preferencias").

Estas propiedades por defecto son:

  • Colores de los nodos (de probabilidad, decisión y utilidad)
  • Colores de las celdas de las tablas
  • Directorios de ubicación de los idiomas para la aplicación
  • Posición inicial relativa de la ventana de CARMEN
  • Tamaño inicial de la ventana de ayuda
  • Idioma de usuario
  • Ultimos ficheros abiertos (se pone a ninguno)
  • Ultima vez que se usó la aplicación

 

Propiedades avanzadas

Por último, hay un conjunto de propiedades que son sólo accesibles para usuarios avanzados o desarrolladores y que no están accesibles desde el menú mencionado anteriormente.

Estas propiedades son:

  • Valores de posicion de ventanas
  • Tamaños de letra
  • Tamaños de objetos visuales
  • Configuración de opciones en los paneles de trabajo
