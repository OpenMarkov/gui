Definir tabla de relaciones del nodo

Una de las cosas más importantes que debe hacer el usuario es definir la tabla de relaciones del nodo.

Dependiendo del tipo de nodo que se esté editando, la tabla de probabilidades es diferente.

Esta tabla está dentro de las probabilidades del nodo en la pestaña de "Tabla de relación" (o Tabla de Utilidad o Tabla de Decisión) 

Nodo de elección

En el caso de un nodo de eleccion (chance), como su nombre indica tendrá una tabla donde se recogen los valores de probabilidad que sus estados pueden tomar en relación a sus padres (si los tiene) o su valor determinista

Cuando el nodo se está creando esta tabla asigna valores iguales a cada uno de los estados del nodo

Cuando el nodo existe anteriormente, y por tanto, tiene una tabla de potencial, cuando se añade un nuevo estado al nodo, el sistema asigna un valor 0.0 a esa nueva probabilidad

Cuando el nodo existe anteriormente, y por tanto, tiene una tabla de potencial, cuando se elimina un estado al nodo, el sistema distribuye el valor de probabilidad entre los otros estados del nodo (o si es un nodo determinista y el estado eliminado es el que le hacia con valor igual a 1, le asigna dicho estado a uno de los otros estados)

 

 

Nodo de decision

El panel de entrada de datos tiene una primera decisión. Por defecto, se le asigna "Decisión Optima", marcando el check box correspondiente, junto con los check box de Probabilista y Determinista. En este caso de decisión optima, no hay tabla mostrada, ni tipos de relación ni nada más que los 3 check box mencionados.

Si el usuario decide marcar Probabilista, aparece el resto del panel como si fuera un nodo de elección

Si el usuario decide marcar Determinista, aparece el resto del panel como si fuera un nodo de elección

 

Nodo de utilidad

En el panel, no existen tipos de relación (general, familia AND, familia OR) ni otros elementos en la ventana. En cambio, aparece un tipo nuevo de relación denominado "UTILIDAD" y una tabla de datos que contiene los estados de los padres y, en la ultima fila, el nombre del nodo y en las celdas de coordenadas, valores de la utilidad.

Si el nodo es nuevo, estos valores están en 0.0.

Si el nodo es viejo, presentan el valor correspondiente.

No hay restricciones de valor.
