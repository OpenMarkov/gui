Comenzar

Navegar en el editor de red CARMEN y en la ventana de mensajes

Al iniciar CARMEN, dos ventanas diferentes aparecerán en tu pantalla: la ventana principal CARMEN con una zona en blanco para el área de edición de red; y la ventana de mensajes de CARMEN, donde se mostrarán todos los mensajes internos para confirmar la apertura y el cierre de redes y que, principalmente, está diseñada para capturar todos los mensajes internos y errores del sistema.

Inténtalo ahora...

Para ver lo fácil que es añadir/corregir/modificar los nodos probabilistas en CARMEN, prueba los siguientes pasos:  

  • Crear una nueva red
  • Crear un nodo de Probabilidad (en una Red Bayesiana o en un Diagrama de Influencia)
  • Crear un nodo de Decisión (en un Diagrama de Influencia)
  • Crear un nodo de Utilidad (en un Diagrama de Influencia)
  • Crear un enlace entre dos nodos
  • Establecer las propiedades del nodo
  • Seleccionar algoritmos
  • Establecer tablas de probabilidad
  • Guardar la red
