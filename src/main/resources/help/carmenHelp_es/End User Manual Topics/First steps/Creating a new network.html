Crear una nueva red

Inténtalo ahora siguiendo los pasos que aparecen a continuación. Cuando hayas creado tu nueva red, verás su representación gráfica en el área de red, pero sólo verás una ventana con un área de dibujo vacía.

  1. Selecciona "Nueva Red" en el Menú Archivo o presiona el icono "Nueva red" de la parte superior de la barra de herramientas.
  2. El cuadro de diálogo de las "Propiedades de Red" aparecerá, con la pestaña "Definición" activada.
  3. Escribe el nombre de la nueva red (este nombre será también el nombre por defecto para el fichero de red cuando se grabe).
  4. En este panel de definición, puedes establecer valores para el Tipo de Red y un comentario.
  5. Presiona en la pestaña "Variables".
  6. Ahora puedes seleccionar el tipo de variable (sólo Discreta en esta versión, y también Continua en las siguientes versiones) y los estados por defecto de los nodos.
  7. Por último, si se necesita, tienes la posibilidad de establecer otras propiedades en la pestaña "Otras Propiedades", con un conjunto intuitivo de botones de navegación y con la posibilidad de editar directamente en la tabla.
  8. Presiona Aceptar para crear el nuevo nodo.

Cada nodo de la red tendrá sus propias propiedades, tal y como se mostrará más adelante.
