Guardar la red

Inténtalo ahora siguiendo los pasos que aparecen a continuación. Cuando hayas creado tu nueva red, querrás almacenarla de forma segura en tu ordenador. 

  1. Selecciona "Guardar red" (o "Guardar como...) en el Menú Editar o presiona el icono "Guardar la red actual" de la parte superior de la barra de herramientas.
  2. Aparecerá el cuadro de diálogo de Guardar Red.
  3. Selecciona el directorio donde deseas guardar la red y escribe un nombre para ella.
  4. Verás que el tipo de fichero que se crea por defecto es "Archivos OpenMarkov (.pgmx)", pero puedes seleccionar también el tipo del programa Elvira "Archivos Elvira (.elv)"
  5. Presiona Aceptar para guardar la red.
