Abrir/Guardar base de datos

En la parte superior de la pestaña 'General' se nos ofrece la posibilidad de cargar una base de datos. Para ello basta con pinchar en el botón 'Abrir' y elegir el fichero correspondiente en el menú que se despliega. Los formatos de bases de datos aceptados por Carmen son:

  1. Formato .dbc: Formato de bases de datos usado en Elvira.

  2. Formato .arff: Formato de bases de datos usado en Weka.

  3. Formato .xls: Formato usado en Microsoft Excel.

Una vez elegido el fichero a partir del cual se quiere cargar la base de datos, la opción 'Guardar como' está disponible para guardar la base de datos previamente cargada, en uno de los formatos indicados. Esta función puede ser útil, entre otras cosas, para transformar fácilmente bases de datos entre distintos formatos y así, poder comparar los modelos obtenidos en Carmen, Elvira y Weka.
