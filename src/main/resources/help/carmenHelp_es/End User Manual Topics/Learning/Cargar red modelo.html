Cargar red modelo

En la parte media de la pestaña 'General' se dan tres opciones para seleccionar una red modelo:

  1. No usar red modelo: No se usará ninguna red modelo durante el aprendizaje.

  2. Abrir red modelo desde archivo: Tras elegir esta opción, es necesario cargar un fichero con una descripción de la red modelo en formato Elvira o XML. Para ello, basta con pinchar en el botón Abrir que se encuentra debajo de las opciones de selección de red modelo, y seleccionar el archivo correspondiente.

  3. Tomar red abierta en Carmen: Al elegir esta opción se usa como red modelo la red que esté abierta en ese momento en la pantalla principal de Carmen. En caso de que no haya ninguna red abierta se devuelve un mensaje de error al usuario y se marca la opción 'No usar red modelo'.
